# Nonstop: 대학 생활 필수 앱

**Nonstop**은 우즈베키스탄 대학생들을 위한 "에브리타임" 스타일의 종합 커뮤니티 및 시간표 관리 애플리케이션입니다.

---

## 🎯 프로젝트 소개

Nonstop은 우즈베키스탄 대학생들의 편리하고 즐거운 학교 생활을 돕기 위해 탄생했습니다. 시간표 관리, 커뮤니티, 채팅 등 대학 생활에 꼭 필요한 기능들을 하나의 앱에서 제공하여 학생 간의 소통을 활성화하고 학업 관리를 효율적으로 만듭니다.

---

## 🚀 주요 기능

### 👤 사용자 인증 및 계정 관리
- **회원가입**: 신규 회원 가입 시 백엔드로부터 최신 정책을 받아 동의 처리 (필수)
- **유효성 검사**: 이메일, 닉네임 작성 시 실시간 안내 제공
- **로그인**: 이메일/비밀번호 기반 로그인 및 JWT(Access/Refresh Token) 발급
- **토큰 관리**: Access Token 갱신 및 Refresh Token 무효화 로직 처리
- **학교 인증**: 학교 이메일로 인증 코드 발송 및 인증 처리
- **프로필 관리**: 본인 정보 조회 및 프로필(닉네임, 학교 정보 등) 수정
- **보안**: 비밀번호 변경 및 계정 비활성화(Soft Delete) 기능

### 🏫 학교 및 커뮤니티
- **학교 정보**: 전체 학교 목록 검색 및 상세 정보, 개설 학과 목록 조회
- **커뮤니티**: 내 학교의 커뮤니티 및 게시판 목록 조회
- **게시글**:
    - 목록 조회 (페이징), 상세 조회 (조회수, 좋아요, 댓글 수 포함)
    - 검색 (제목, 내용, 닉네임), 인기 게시글 조회 (좋아요/조회수 순)
    - 작성, 수정, 삭제 및 신고
    - 좋아요 토글 기능 및 내가 좋아요 한 게시글 조회
- **댓글**:
    - 계층형 댓글/대댓글 목록 조회
    - 작성, 수정, 삭제 및 신고
    - 좋아요 토글 기능 및 내가 좋아요 한 댓글 조회

### 💬 소셜 및 채팅
- **친구**: 친구 목록 조회, 요청/수락/거절/취소 및 사용자 차단
- **채팅**:
    - 1:1 채팅방 목록 조회, 생성, 퇴장
    - 이전 채팅 내역 조회 (커서 기반 페이징)
    - 실시간 메시지 전송 및 마지막 읽음 처리

### 🕒 시간표
- **학기 관리**: 시간표 설정을 위한 학기 정보 조회
- **시간표 관리**:
    - 내 시간표 목록 조회, 생성, 이름/공개여부 수정 및 삭제
    - 시간표에 강의 추가, 수정, 삭제
- **시간표 공유**: 친구 또는 전체 공개된 다른 사용자의 시간표 조회

### ⚙️ 알림 및 설정
- **알림**: 공지사항, 채팅, 댓글 등 새로운 소식에 대한 알림 목록 조회
- **알림 관리**: 특정 알림 또는 모든 알림 읽음 처리
- **앱 설정**: 언어 설정 등 개인화 기능
